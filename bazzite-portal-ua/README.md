# Портал Bazzite українською

`portal_ua` — україномовна оболонка над штатним Bazzite Portal.

Це **не форк**: під час запуску скрипт читає штатні
`/usr/bin/yafti_gtk.py` та `/usr/share/yafti/yafti.yml`, накладає переклад
у пам'яті й запускає результат. Жодних файлів системи не змінює, тож
оригінальний портал працює далі як був.

## Файли

| файл | що це |
|---|---|
| `uk.map` | власне переклад (`ключ = текст`) — тільки його зазвичай і правлять |
| `launcher.py` | логіка накладання + переклад рядків самого GTK-інтерфейсу |
| `build.py` | збирає `dist/portal_ua` з двох попередніх + чинного `yafti.yml` |
| `dist/portal_ua` | готовий однофайловий скрипт, який ставиться в систему |

## Збірка та встановлення

```bash
./build.py
sudo install -m 0755 dist/portal_ua /usr/local/bin/portal_ua
```

`/usr/local` на Bazzite — це симлінк на `/var/usrlocal`, тому встановлене
переживає оновлення образу й `rpm-ostree reset`.

## Використання

```bash
portal_ua               # портал українською
portal_ua --no-commands # без рядків з командами під пунктами
portal_ua --report      # що лишилось неперекладеним / що розійшлося з оригіналом
portal_ua --english     # оригінальний портал без перекладу
```

## Перегляд команд без їх виконання

Оригінальний портал такого не має взагалі — це дописано тут.

* під заголовком кожного пункту — команда, яку він виконає
  (`ujust setup-virtualization …`);
* наведення миші — та сама команда повністю, разом зі скриптом перевірки
  стану, який портал виконує сам, без кліку;
* **ПКМ на пункті** (або кнопка «Показати, що виконається…» у вікні дії) —
  вікно з повним скриптом **і тілом рецепта `ujust`**. Саме там видно
  справжню роботу: у `ujust setup-virtualization virt-on` це
  `flatpak install --system --assumeyes flathub org.virt_manager.virt-manager
  org.virt_manager.virt_manager.Extension.Qemu`. Вікно нічого не запускає.

Рецепти читаються через `just --justfile /usr/share/ublue-os/justfile
--show <recipe>` і кешуються на час сеансу.

Реалізовано як monkey-patch методів `create_action_item` і
`build_action_dialog_content` (дописується в кінець коду, змінна `ADDON`
у `launcher.py`), а не як правка тексту — тож переживе переписування
upstream'ом усього, крім імен цих методів. Якщо метод зникне — портал
працюватиме без перегляду команд, а не впаде.

## Після оновлення образу Bazzite

У `dist/portal_ua` запечено знімок англійських рядків. Якщо upstream
змінив формулювання, портал показує **англійський** оригінал (а не
застарілий переклад) і `--report` каже, що саме розійшлося. Нові дії
Bazzite з'являються самі, теж англійською.

Щоб підтягнути зміни:

```bash
./build.py           # покаже «БЕЗ ПЕРЕКЛАДУ» та «ЗАЙВЕ В uk.map»
# дописати нові рядки в uk.map, повторити build.py
sudo install -m 0755 dist/portal_ua /usr/local/bin/portal_ua
```

## Ключі в `uk.map`

* `scr:<індекс>:title|desc` — вкладка
* `act:<id>:title|desc` — дія (`id` береться з `yafti.yml`)
* `opt:<англійський напис>` — кнопка у вікні дії
* значення `=` означає «лишити англійською» (назви брендів)

Рядки самого інтерфейсу (пошук, «Запускати при вході», статуси, помилки)
живуть у словнику `UI` всередині `launcher.py` — там ключ це точний
фрагмент коду `yafti_gtk.py`.
